- [⚙️ 모터 세팅](https://app.notion.com/p/40f9f50be3fc800f87f4f70a8d9c05ec): Windows PC 준비, 펌웨어 올리기, 드라이버 설정
- [📊 액추에이터 측정 결과](https://app.notion.com/p/40f9f50be3fc81b38370ca54d97d96ea): 강성·마찰·배선 측정 결과
